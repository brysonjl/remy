# Code of conduct

We want project discussions to be useful, respectful, and welcoming to people
with different backgrounds and levels of experience.

- Discuss ideas and behavior respectfully; give actionable technical feedback.
- Respect names, identities, privacy, and reasonable boundaries.
- Avoid harassment, discrimination, threats, sexualized conduct, personal
  attacks, and deliberate disruption.
- Never publish another person's private information or sensitive dictation,
  credentials, or diagnostic data without permission.

These expectations apply to issues, pull requests, discussions, and other spaces
maintained for this project. Maintainers may edit or remove inappropriate content,
limit participation, or block participants based on severity and repeated behavior.
Maintainers are expected to follow the same standards.

For a conduct concern, contact a maintainer through an available private channel.
If no private channel is published, ask for one without posting private details or
naming affected people publicly. Security vulnerabilities should follow
[SECURITY.md](SECURITY.md). A public launch should identify an accessible private
conduct contact; no specific response time is promised.
