## Running the optional local speech tests

Ordinary unit tests and deterministic synthetic recovery tests do not require speech
recordings. Model-backed speech tests retain their existing explicit opt-in flags
and accuracy assertions. Their recording loader additionally requires an absolute
`REMY_SPEECH_FIXTURES_DIR`. There is no bundle-resource or source-folder fallback.
Absent optional recordings produce an explicit XCTest skip; an invalid configured
directory, nonregular fixture input or invalid audio produces a test failure.
Missing Mandarin/Nemotron inputs are checked before model downloads begin. A skip
is not a successful ASR quality measurement.

Supply recordings you are entitled to use locally. Mandarin tests expect the
synthetic phrases listed in `MandarinFixtureTests.references`; `zh-long.wav` must
match the generator passage and duration constraints. Recovery/offline English
checks expect `en-recovery.wav` to contain the words “weather” and “cancellation”
at the beginning/end regions. Use 16 kHz mono WAVs. The optional real-voice test
uses `zh-real.wav` plus its UTF-8 `zh-real.txt` reference in the same local directory.
Changing the corpus requires its own review of reference text and quality thresholds.

Example from the repository root, using a local directory whose contents you have
reviewed for that use:

```sh
TEST_RUNNER_REMY_SPEECH_FIXTURES_DIR="$PWD/.local/speech-fixtures/my-reviewed-corpus" \
TEST_RUNNER_RUN_RECOVERY_ASR_TESTS=1 \
app/scripts/remy-build.sh test -parallel-testing-enabled NO \
  '-only-testing:Dictate AnywhereTests/RecoveryASRSmokeTests'
```

For Mandarin or Nemotron, use `TEST_RUNNER_RUN_MANDARIN_ASR_TESTS=1` or
`TEST_RUNNER_RUN_NEMOTRON_ASR_TESTS=1` and the corresponding test class. These opt-in
suites may load/download models as described by their test gates. The existing
local-audio benchmark's separate recording/reference path settings remain unchanged.
Ordinary credential-free CI does not set these flags or supply personal recordings.
Xcode's `TEST_RUNNER_` prefix forwards the variables into the test process; when
launching tests through another runner, set the unprefixed variables it receives.

The optional Mandarin generator now requires an explicit local output directory:

```sh
app/scripts/generate-mandarin-fixtures.sh "$PWD/.local/speech-fixtures/generated-mandarin"
```

Run it only after reviewing the applicable voice terms for your intended use.
The script does not claim voice-output redistribution rights and its output is not
a replacement asset approved for publication. It does not generate the English or
real-voice recordings. Never commit generated audio or personal reference transcripts.

The long-dictation harness similarly generates audio locally and excludes generated
audio from Git. Personal microphone recordings, transcripts and evaluations require
explicit publication review and are not covered by an application source license.
